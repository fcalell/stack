# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub
Security Advisories on this repository:

<https://github.com/fcalell/stack/security/advisories/new>

Include the affected package and version, what an attacker can do, and steps to reproduce. You will
get an acknowledgement, and a fix is released with an advisory crediting you unless you prefer
otherwise.

## Supported versions

Stack is pre-1.0. Only the latest published release of the `@fcalell/*` packages receives fixes.
