# Empty state

The range an empty state is measured against in a [design critique](../design-critique.md), and the
executions behind it. Read the measurements as the [references](../references.md) page sets out.

## Range

title 13–18 (13–14/600 in dense tools), body 12–13 muted, icon 20–64 or illustration 130–190, one primary 28–32 radius 6 carrying the only accent; column 300–360 centred; bare canvas or a radius-8 hairline frame.
